SUJITH PORTFOLIO WEBSITE

FILES
- index.html: website structure and content
- styles.css: all visual styles, responsive layouts, and animations
- script.js: mobile navigation and current footer year
- assets/sujith-profile.png: profile photo
- assets/Sujith-Resume.pdf: résumé download

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Keep the assets folder beside index.html.

HOW TO PUBLISH FREE
Netlify: Sign in, choose Add new site / Deploy manually, then drag the extracted portfolio folder into the deploy area.
GitHub Pages: Create a repository, upload all files/folders, then enable Pages in repository settings.

CUSTOMIZE
- Edit your details and project descriptions in index.html.
- Change colors, spacing, and layouts in styles.css.
- Replace the profile photo at assets/sujith-profile.png if needed.
- Add actual GitHub and LinkedIn profile URLs when available. Those links were not included in the résumé text provided.
